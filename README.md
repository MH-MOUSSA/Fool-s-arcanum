# Fool's Arcanum

Assistant IA pour étudiants en licence (filières scientifiques).

## Vision
Aider les étudiants à assimiler efficacement leurs cours grâce à un suivi personnalisé, adapté à leur niveau.

## Stack technique
- Frontend : React + Vite
- Backend : FastAPI (Python)
- Base de données : PostgreSQL
- Versionnement : Git + GitHub

## Roadmap
- V1 : Chat fonctionnel
- V2 : Intégration d'une IA réelle
- V3 : Authentification
- V4 : Import de PDF
- V5 : Analyse d'images
- V6 : Génération de quiz
- V7 : Fiches de révision
